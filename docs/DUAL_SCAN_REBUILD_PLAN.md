# AI SIGNAL RADAR PRO — Clean Rebuild Specification

สถานะ: เริ่มต้นออกแบบระบบใหม่ (Clean Start)
วันที่: 31 ตุลาคม 2026
Branch: `ocr-dual-scan-clean`

## เป้าหมาย
สร้าง Android APK ใหม่สำหรับอ่านข้อมูลจากหน้าจอแพลตฟอร์มเทรดจริง รองรับตลาดหลัก (Non-OTC) และ OTC โดยผู้ใช้เป็นผู้เลือก/เปิดกราฟ และเป็นผู้ตัดสินใจส่งคำสั่งซื้อขายเอง แอปไม่มีการล็อกอินโบรกเกอร์และไม่มีระบบส่งคำสั่งซื้อขายอัตโนมัติ

## รูปแบบการสแกนที่ผู้ใช้เลือก: C — Dual Scan
1. **Manual Scan:** ผู้ใช้เลือกคู่เงิน/เปิดกราฟที่ต้องการ แอปอ่านชื่อคู่เงิน ประเภทตลาด ราคา เวลา และข้อมูลกราฟจากหน้าจอ
2. **Auto Scan:** แอปจัดคิวตรวจคู่เงินหลายคู่และแสดงคู่ที่ข้อมูลพร้อม/มีเงื่อนไขน่าสนใจ โดยต้องแสดงสถานะชัดเจนว่ากำลังอ่านคู่ใดและอ่านเมื่อใด

### ข้อจำกัดสำคัญของ Auto Scan
OCR/MediaProjection อ่านได้เฉพาะสิ่งที่ปรากฏอยู่ในภาพหน้าจอ ณ เวลานั้น ไม่สามารถดึงราคาของทุกคู่เงินที่ไม่ได้เปิดหรือไม่ปรากฏบนหน้าจอได้เอง
- หากแพลตฟอร์มมี watchlist ที่แสดงชื่อคู่และราคาหลายคู่พร้อมกัน ให้ OCR อ่านรายการนั้นได้
- หากต้องเปลี่ยนกราฟทีละคู่ การสลับคู่จะทำได้ต่อเมื่อมีวิธีนำทางที่ผู้ใช้อนุญาตและทดสอบได้จริง ไม่รับประกันว่าแอปทุกแพลตฟอร์มจะรองรับการสลับอัตโนมัติ
- ห้ามสร้างราคาแทนคู่ที่ไม่ได้อ่าน และห้ามแสดงคู่ที่ยังไม่มีข้อมูลเป็นสัญญาณสด

## สถาปัตยกรรมที่ต้องสร้าง
1. **Android Capture Layer**
   - MediaProjection พร้อม foreground service และการแจ้งเตือนตามข้อกำหนด Android
   - Overlay ที่มีปุ่มเริ่ม/หยุด/ย่อ/ขยาย และสถานะการจับภาพ
   - ROI crop แยกบริเวณชื่อคู่เงิน ป้ายตลาด ราคา เวลา และกราฟ
2. **OCR + Vision Layer**
   - On-device ML Kit Text Recognition สำหรับข้อความ
   - ตรวจจับตัวเลขราคาโดยรักษาจุดทศนิยมและความละเอียด
   - ใช้ computer vision แยกส่วนแท่งเทียน/กราฟเมื่อจำเป็น; OCR ตัวหนังสืออย่างเดียวไม่สามารถสร้าง OHLC ย้อนหลังได้
   - เก็บ confidence, timestamp, source screenshot frame และสถานะการตรวจสอบทุกค่า
3. **Validation Layer**
   - ตรวจรูปแบบคู่เงินและจำนวนหลักทศนิยม
   - ตรวจความสดของภาพและความต่อเนื่องของเวลา
   - แยก MAIN / OTC จากป้ายตลาดที่อ่านได้ชัดเท่านั้น; หากไม่ชัดให้เป็น UNKNOWN และงดสัญญาณ
   - หากราคาไม่เสถียร อ่านไม่ครบ หรือจับคู่สินทรัพย์ไม่ได้ ให้ WAIT / STANDBY
4. **Market Data Builder**
   - สร้าง price ticks และแท่ง 1 นาทีจากภาพที่อ่านได้ต่อเนื่อง
   - ระบุชัดเจนว่าประวัติแท่งที่สร้างจากการเริ่มจับภาพมีข้อมูลย้อนหลังจำกัด
   - ไม่อ้างว่าเป็น feed ทางการของโบรกเกอร์ และไม่ผสมราคา OTC กับราคา Forex ตลาดหลัก
5. **Analysis Engine**
   - คำนวณ EMA, RSI, MACD, momentum และ price action จากข้อมูลที่ผ่าน validation
   - แสดงเหตุผลประกอบคะแนนและสัญญาณ CALL / PUT / STANDBY
   - แสดง confidence เป็นคะแนนคุณภาพข้อมูล/ความสอดคล้องของเงื่อนไข ไม่ใช่โอกาสชนะที่รับประกัน
   - ป้องกันสัญญาณซ้ำในแท่งเดียวและบันทึกผลเพื่อทดสอบย้อนหลัง
6. **Storage & UI**
   - เก็บการตั้งค่าและประวัติในเครื่องก่อน; การ sync backend เป็นส่วนเสริม
   - Dashboard แสดงโหมด Auto/Manual, คู่เงิน, MAIN/OTC, ราคา, เวลา, ความสด, confidence, เหตุผล และประวัติ
   - ผู้ใช้ต้องกดซื้อขายเอง ไม่มี broker credentials หรือ auto-trading

## เกณฑ์ผ่านก่อนเรียกว่าใช้งานได้
- ทดสอบกับภาพจริงของตลาดหลักและ OTC อย่างน้อยหลายคู่เงิน โดยบันทึกผล OCR เทียบกับตัวเลขบนหน้าจอ
- ราคาและชื่อคู่เงินต้องไม่สลับกันเมื่อเปลี่ยนคู่
- ประเภทตลาดต้องไม่เดา หากอ่านไม่ชัดต้องเป็น UNKNOWN
- เวลาและ timestamp ต้องต่อเนื่องและไม่ใช้ข้อมูลเก่าเป็นข้อมูลสด
- เมื่อหยุด/เริ่ม capture ใหม่ permission และ foreground service ต้องทำงานตาม Android version ที่ทดสอบ
- Auto Scan ต้องระบุข้อจำกัดของ watchlist/การเปลี่ยนคู่ให้ชัด
- Build APK สำเร็จและติดตั้งทดสอบบนอุปกรณ์จริงก่อนส่งลิงก์ดาวน์โหลด
- ห้ามรับประกัน Win Rate หรือแสดงผลทดสอบที่ไม่ได้ทำจริง

## ลำดับพัฒนา
1. ตรวจและสร้าง Android project ใหม่แยกจากโค้ด OCR เดิม
2. ทำ capture + overlay ให้เริ่ม/หยุดได้จริง
3. ทำ OCR เฉพาะ ROI และแสดงชื่อคู่เงิน/ตลาด/ราคา/เวลาแยกช่อง
4. ทำ validation และหน้าจอทดสอบความถูกต้องโดยยังไม่ออกสัญญาณ
5. ทำ Auto/Manual scan ตามข้อจำกัดของแพลตฟอร์ม
6. สร้าง ticks/candles และ analysis engine
7. บันทึกประวัติ ทดสอบบนเครื่องจริง และทำ Release APK เมื่อผ่านเกณฑ์
