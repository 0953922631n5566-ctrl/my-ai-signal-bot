# 8xTrade Screen Companion — AI Signal Radar

ส่วนเสริม Android อ่านราคา 8xTrade ด้วย MediaProjection + ML Kit OCR ในเครื่อง แล้วส่งเฉพาะคู่เงิน ราคา เวลา และค่า heuristic ไปยัง Render ผ่าน HTTPS

## โหมดใน Telegram Mini App
- **MODE A — อ่านหน้าจอ 8xTrade:** ใช้เฉพาะ `/api/screen/status` จาก OCR; สร้างแท่ง 1 นาทีจากตัวอย่างราคาหน้าจอ แล้ววิเคราะห์ EMA 9/21/50, RSI 14 และ MACD
- **MODE B — ตลาดหลัก:** ใช้เฉพาะ Twelve Data ตามระบบเดิม
- เมื่อสลับโหมด ระบบล้างสัญญาณเก่าก่อนอ่านแหล่งข้อมูลใหม่ ไม่ผสมข้อมูล A/B
- ถ้าข้อมูลไม่สด ราคาอ่านไม่ชัด หรือแท่งไม่สมบูรณ์ ต้องแสดง STANDBY

## ขั้นตอนตั้งค่า
1. Merge PR ที่รวมโค้ด Companion + API + Mini App แล้วค่อย deploy Render
2. ใน Render Dashboard → Environment เพิ่ม `SCREEN_INGEST_TOKEN` เป็นค่าสุ่มลับอย่างน้อย 32 ตัวอักษร
3. ใส่ token เดียวกันใน Android Companion เท่านั้น ห้าม commit token ลง GitHub หรือใส่ในหน้า Mini App
4. ใช้ URL HTTPS ของ Render ในแอป Android และใส่คู่เงิน เช่น `EUR/USD`
5. ปรับพื้นที่อ่านราคา `x,y,width,height` เป็นเปอร์เซ็นต์ของหน้าจอให้ครอบเฉพาะตำแหน่งราคาเดียว ตัวอย่าง `20,10,30,12` เป็นเพียงตัวอย่าง ต้องปรับตามหน้าจอจริง
6. กดเริ่มจับภาพและอนุญาต MediaProjection เมื่อ Android ขออนุญาต จากนั้นคงหน้า 8xTrade ไว้ด้านหน้า
7. เปิด Mini App แล้วเลือก MODE A ตรวจสอบว่าราคาเปลี่ยนตรงกับกราฟและสถานะไม่ค้างเป็นข้อมูลเก่า

## สร้าง APK
- เปิดโฟลเดอร์ `android/` ใน Android Studio โดยใช้ JDK 17
- หรือดาวน์โหลด artifact `ai-signal-radar-screen-companion-debug` จาก GitHub Actions workflow ที่ build สำเร็จล่าสุด
- Android Companion ต้องได้รับอนุญาตจับภาพใหม่ตามที่ระบบ Android กำหนดในแต่ละเซสชัน

## ข้อจำกัดของ OCR และแท่งราคา
- ไม่เข้าสู่ระบบ 8xTrade ไม่เก็บรหัสผ่าน/OTP ไม่อัปโหลดภาพหน้าจอ และไม่มีคำสั่งซื้อขายอัตโนมัติ
- OCR ทำงานบนเครื่องและส่งเฉพาะข้อมูลตัวเลขไป Render
- ตัวแยกราคายอมรับเลขทศนิยม 2–6 ตำแหน่ง เพื่อรองรับคู่เงิน JPY และคู่เงินทั่วไป แต่ยังอาจอ่านเลขผิดได้ จึงต้องปรับ ROI ให้แคบและตรวจสอบราคาเทียบกราฟจริง
- ค่าความเชื่อมั่น 0.80 เป็น heuristic ที่กำหนดจากฝั่งแอป ไม่ใช่ความน่าจะเป็นที่ผ่านการ calibrate
- แท่ง 1 นาทีเป็น OHLC ที่ประมาณจากตัวอย่าง OCR ไม่ใช่แท่งเทียนทางการจากโบรกเกอร์ ระบบต้องมีอย่างน้อย 10 ตัวอย่างต่อแท่ง และจะรีเซ็ตประวัติเมื่อขาดช่วง/เปลี่ยนคู่เงินเพื่อไม่สร้างแท่งปลอม
- ต้องสะสมแท่งปิดที่ผ่านเกณฑ์อย่างน้อย 50 แท่ง (ประมาณ 50 นาทีต่อเนื่อง) ก่อน EMA50 และสัญญาณจะพร้อม ข้อมูลในหน่วยความจำหายเมื่อ Render restart
- หากราคา/คู่เงินไม่ตรงกับกราฟ ให้หยุดทดสอบก่อน อย่าใช้เงินจริงจนกว่าจะตรวจสอบความถูกต้องและทดสอบในบัญชีทดลองแล้ว
