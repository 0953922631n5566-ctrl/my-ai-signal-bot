# 8xTrade Screen Companion — ส่วนเสริม AI Signal Radar

ชุดนี้เพิ่มแหล่งข้อมูล OCR จากหน้าจอ Android โดยรักษาแหล่งข้อมูล Twelve Data เดิมไว้เป็นค่าเริ่มต้น และมีปุ่มเลือกแหล่งข้อมูลใน Mini App

## สถานะ
- โค้ดถูกเพิ่มในสาขาแยกและเสนอผ่าน Pull Request
- `server.js` เชื่อม `screen-source.js` แล้วในสาขานี้
- ยังไม่ได้ Deploy Render, ยังไม่ได้ Build APK และยังไม่ได้ทดสอบกับหน้าจอ 8xTrade จริง

## ก่อนทดสอบ
1. ตรวจสอบและ merge Pull Request นี้ก่อน แล้วค่อย deploy ตามขั้นตอนของคุณ
2. ใน Render Dashboard > Environment เพิ่ม `SCREEN_INGEST_TOKEN` เป็นค่าสุ่มยาวอย่างน้อย 32 ตัวอักษร
3. ใส่ค่า token เดียวกันในแอป Android Companion (token ไม่ควร commit ลง GitHub หรือใส่ในหน้า Mini App)
4. เปิดแอป Android, ใส่ URL HTTPS ของ Render, token และคู่เงิน เช่น `EUR/USD`
5. กดเริ่มจับภาพและยืนยันกล่องอนุญาตของ Android จากนั้นเปิดหน้า 8xTrade
6. เลือกปุ่ม `8xTrade Screen` ใน Mini App และตรวจสอบสถานะที่ `/api/screen/status`

## สร้าง Android APK
1. เปิดโฟลเดอร์ `android/` ใน Android Studio (JDK 17)
2. รอ Gradle Sync แล้วเลือก Build > Build APK(s)
3. ติดตั้ง APK บน Xiaomi 11T (Android 14, RAM 8 GB)
4. อนุญาตการจับภาพหน้าจอทุกครั้งที่ Android ขออนุญาต

## ความปลอดภัย
- ไม่เข้าสู่ระบบ 8xTrade ไม่เก็บรหัสผ่าน/OTP และไม่มีคำสั่งซื้อขาย
- OCR ทำงานบนเครื่อง และส่งเฉพาะตัวเลขราคา คู่เงิน เวลา และค่า heuristic confidence ไป Render; ไม่อัปโหลดภาพหน้าจอ
- API รับข้อมูลต้องใช้ `Authorization: Bearer <SCREEN_INGEST_TOKEN>`
- ใช้ HTTPS เท่านั้น

## ข้อจำกัดที่ต้องรู้ก่อนใช้เงินจริง
- การจับภาพเป็นการจับทั้งหน้าจอ หากสลับไป Telegram ระบบอาจอ่านหน้าจอ Telegram แทนกราฟ
- ตัวแยกราคาปัจจุบันส่งข้อมูลเมื่อพบเลขทศนิยมรูปแบบราคาเพียงค่าเดียวบนภาพเท่านั้น หากหน้าจอแสดงตัวเลขราคาอื่นหลายตำแหน่ง อาจไม่ส่ง tick และระบบจะแสดง STANDBY; ต้องปรับ OCR/พื้นที่อ่านให้ตรงกับหน้าจอจริง
- ค่า confidence เป็น heuristic จากการพบตัวเลขไม่กำกวม ไม่ใช่ค่าความเชื่อมั่นที่ ML Kit รับประกัน
- แท่ง 1 นาทีสร้างจากตัวอย่างราคา OCR ไม่ใช่ OHLC อย่างเป็นทางการจาก 8xTrade
- ต้องสะสมแท่งปิดอย่างน้อย 50 แท่ง (ประมาณ 50 นาทีต่อเนื่อง) ก่อนที่ EMA50 จะพร้อม; หาก Render restart ข้อมูลชั่วคราวในหน่วยความจำจะเริ่มสะสมใหม่
- หากราคา/เวลา OCR ไม่ตรงกับกราฟ ให้หยุดทดสอบก่อน อย่าใช้เงินจริงจนกว่าจะตรวจสอบความถูกต้องและทดสอบในบัญชีทดลองแล้ว

ระบบนี้เป็นตัวช่วยแสดงข้อมูล ไม่รับประกันผลกำไรหรือความแม่นยำของสัญญาณ
